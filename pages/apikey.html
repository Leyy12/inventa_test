Test your InventaAPI key

The key is read from INVENTA_API_KEY in your .env file. It is never typed into or shown on this website. Press Test key to call GET /daas/v1/catalog and see the products linked to it.

Put the key in your code (.env)

Create a file named .env in the project folder (next to package.json) and paste your key from inventaapi.shop → Dashboard → API Keys:


      


      
    
        
  1. Replace paste-your-inventa-api-key-here with your key and save the file.
    2. 
        
  2. Restart the server: stop it (Ctrl + C) and run npm run dev again.
    3. 
        
  3. Press Re-check .env, then Test key.
    4. 
        
  4. Go to Products → Sync from API. The POS now sells exactly the products on that key.
    5. 
        
  5. On Vercel: add INVENTA_API_KEY under Project → Settings → Environment Variables, then redeploy.
    6. 
      


      
Calling the API from your own code:

      

        
const res = await fetch(`${process.env.INVENTA_API_URL}/daas/v1/catalog`, {
  headers: { 'x-api-key': process.env.INVENTA_API_KEY },
});
const { products, meta } = await res.json();

Test an InventaAPI key

Paste the key from inventaapi.shop → Dashboard → API Keys. We call GET /daas/v1/catalog with it and show the products linked to that key. Leave it empty to test the key in your .env.

Use it in your project (.env)

Put the key in a .env file in the project root (next to package.json). Never commit that file.

Calling the API from your own code:

      

        
const res = await fetch(`${process.env.INVENTA_API_URL}/daas/v1/catalog`, {
  headers: { 'x-api-key': process.env.INVENTA_API_KEY },
});
const { products, meta } = await res.json();

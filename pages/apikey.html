Test your InventaAPI keys

One key in your .env file serves all three stores; each store gets only its segment's products. The key is never typed into or shown on this website. Press Test to call GET /daas/v1/catalog?segment=… for that store and see its products.

Put the key in your code (.env)

Run npm run setup once. It creates a .env file in the project folder (next to package.json). Open it and paste your key from inventaapi.shop → Dashboard → API Keys after the =:


      


      
    
        
  1. Paste the key and save the file.
    2. 
        
  2. Restart the server: stop it (Ctrl + C) and run npm run dev again.
    3. 
        
  3. Press Re-check .env, then Test on each store.
    4. 
        
  4. Pick a store at the top, then go to Products → Sync from API.
    5. 
        
  5. On Vercel: Project → Settings → Environment Variables → Import .env, choose your .env file, save, then redeploy.
    6. 
      


      
Calling the API from your own code:

      

        
const res = await fetch(`${process.env.INVENTA_API_URL}/daas/v1/catalog?segment=Grocery`, {
  headers: { 'x-api-key': process.env.INVENTA_API_KEY },
});
const { products, meta } = await res.json();

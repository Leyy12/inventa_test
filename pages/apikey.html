Test your InventaAPI keys

Each store has its own key in your .env file. Keys are never typed into or shown on this website. Press Test to call GET /daas/v1/catalog with that store's key and see the products linked to it.

Put the key in your code (.env)

Run npm run setup once. It creates a .env file in the project folder (next to package.json). Open it and paste each key from inventaapi.shop → Dashboard → API Keys after the =:


      


      
    
        
  1. Paste the three keys and save the file. A store without a key just stays empty.
    2. 
        
  2. Restart the server: stop it (Ctrl + C) and run npm run dev again.
    3. 
        
  3. Press Re-check .env, then Test on each store.
    4. 
        
  4. Pick a store at the top, then go to Products → Sync from API.
    5. 
        
  5. On Vercel: Project → Settings → Environment Variables → Import .env, choose your .env file, save, then redeploy.
    6. 
      


      
Calling the API from your own code:

      

        
const res = await fetch(`${process.env.INVENTA_API_URL}/daas/v1/catalog`, {
  headers: { 'x-api-key': process.env.INVENTA_API_KEY_GROCERY },
});
const { products, meta } = await res.json();
